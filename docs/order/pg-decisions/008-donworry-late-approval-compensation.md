# 008. 결제 기한 뒤 늦게 승인된 돈워리 결제는 CakeShop이 보상 취소한다

- 상태: 채택 (2026-11-04, 주문·결제 작업 담당 수민 결정)
- 기록일: 2026-11-04
- 관련 이슈·PR: #24 Codex 리뷰(브라우저 복귀 없이 승인된 결제 복구), #25 Codex 리뷰(보상 복구의 VOIDED 해석),
  DonWorry ADR-0064 남은 결정 "결제 접수 기한이 지난 뒤 늦게 승인된 결제를 누가 취소하는지"

## 해결하려던 문제

돈워리는 결제창 안에서 카드 승인을 끝낸다. 구매자가 탭을 닫거나 복귀 신호가 전달되지 않으면 CakeShop 결제는 READY로 남는다.
보통은 웹훅·조회 배치가 승인을 보고 결제를 완료하지만, 그 전에 결제 기한(10분)이 지나면 다음 일이 생긴다.

- 만료 배치가 주문·결제를 EXPIRED로 바꾼다.
- 이후 결제 완료는 기한 검사(`PAYMENT_EXPIRED`)로 실패한다.

결과적으로 카드에는 승인이 남고 주문은 만료로 끝난다. 돈워리는 기한 직전에 접수된 결제를 기한 뒤에도 처리하므로 이런 늦은 승인이 생길 수 있다.

## 결정

- CakeShop이 "돈워리는 승인 · CakeShop은 기한 지남"을 알게 되면 기존 보상 취소(`SYSTEM_COMPENSATION`)로 돈워리 승인을 취소한다.
  - 알게 되는 경우: 웹훅·조회 배치에서 READY 결제 완료가 `PAYMENT_EXPIRED`로 실패하거나, 결제가 이미 EXPIRED인데 돈워리가 승인을 알릴 때
  - 키는 `COMPENSATE-{결제 ID}`, 사유는 기존 보상 사유와 같다. 같은 키·같은 사유라 웹훅·조회 배치·복구 배치가 여러 번 불러도 돈워리 쪽 취소는 하나다.
- 취소가 바로 끝나지 않으면 보상 요청이 REQUESTED로 남고 기존 복구 배치가 다시 보낸다. 그동안 만료 배치는 그 주문을 건드리지 않는다(기존 조건).
- 조회 배치는 진행 중(REQUESTED) 보상 요청 없이 만료된 돈워리 결제를 결제 생성 후 1시간 동안 다시 조회한다(실패로 닫힌 옛 보상 기록은 막지 않는다). 웹훅이 CakeShop에 닿지 않는 환경(DonWorry ADR-0064 6절)을 대비한 것이다.
- 보상 복구는 돈워리 `VOIDED`를 "승인 안 됨"이 아니라 취소 완료로 반영한다.
  - 돈워리 조회 결과가 VOIDED면 승인 취소 기록(`DW-VOID-{id}`)을 함께 싣는다.
  - 보상 복구 판단(`resolveCompensationState`)만 이 기록을 보고 취소 완료로 본다.
  - 일반 승인 확인은 지금처럼 승인 실패로 본다.

## 선택 이유

- 보상 취소 장치와 SQL이 이미 READY·DONE·EXPIRED 결제를 다루고, 취소 뒤 주문 정리(`cancelAfterPaymentCompensation`)도 EXPIRED 주문을 받는다. 새 테이블이나 상태 없이 감지만 붙이면 된다.
- 결제 기한을 정한 쪽이 CakeShop이라, 기한이 지났는지도 CakeShop이 가장 정확히 안다.

## 검토한 대안

- 돈워리가 기한 뒤 승인을 스스로 취소한다: 돈워리(P4·P5) 코드를 고쳐야 하고, 접수는 기한 전이었는데 승인만 늦은 경우를 가맹점 기한과 맞추기 어렵다.
- 늦게 와도 결제를 완료한다: 결제 기한(재고·쿠폰 예약) 규칙이 깨지고 만료 배치와 완료 로직을 모두 바꿔야 한다.
- 로그만 남기고 사람이 처리한다: 청구가 남은 채 놓칠 수 있다.

## 감수한 비용과 한계

- 매입된(CAPTURED) 결제는 돈워리 환불 실행 연결 전까지 503이라 보상 요청이 계속 재시도된다(연동 문서 4절).
- 결제 생성 후 1시간이 지나 만료된 결제의 늦은 승인은 조회 배치로는 다시 보지 않는다. 그 뒤에는 웹훅(돈워리가 약 24시간 재전송)으로만 잡힌다.
- 다른 결제가 먼저 완료돼 완료가 실패한 경우(예: 같은 주문을 Toss로 결제)는 자동으로 취소하지 않고 경고만 남긴다.
  PG 선택(006)이 진행 중인 돈워리 시도가 있으면 다른 PG로 바꾸지 못하게 막으므로 드물다.

## 다시 검토할 조건

돈워리가 기한 뒤 승인을 스스로 취소하기로 하거나, 결제 기한 정책을 바꿀 때.
